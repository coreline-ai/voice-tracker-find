# Quiet Archive Reference Board

화면을 직접 복제하지 않고 정보 구조와 사용자 흐름만 분석한다.

| 참고 대상 | URL | 적용할 패턴 | 금지 |
|---|---|---|---|
| Google Recorder | https://play.google.com/store/apps/details?id=com.google.android.apps.recorder | 큰 녹음 시간, 명확한 주 동작, 파형 위계 | Pixel 고유 UI·색·아이콘 복제 |
| Bear | https://bear.app/ | Markdown 가독성, 절제된 편집 도구 | Bear 테마·일러스트·태그 구조 복제 |
| Voicenotes | https://voicenotes.com/ | 녹음에서 노트로 이어지는 단순한 흐름 | AI 마법 카피·그라데이션 복제 |
| Material 3 | https://developer.android.com/jetpack/androidx/releases/compose-material3 | 접근성·system UI·상태 기반 component | 기본 component 나열형 화면 |

타 앱 스크린샷과 브랜드 이미지는 앱 번들에 포함하지 않는다.
