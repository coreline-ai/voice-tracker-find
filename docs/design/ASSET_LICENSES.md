# Asset Licenses

## Generated raster assets

`drawable-nodpi`의 7개 WebP는 2026-07-23 이 프로젝트를 위해 OpenAI 내장 이미지
생성 도구로 신규 생성한 뒤 로컬에서 크기 조정·WebP 압축했다. 제3자 이미지,
브랜드 로고, 타 앱 스크린샷은 입력 또는 결과물에 포함하지 않았다.

사용 및 배포는 결과물 생성 시 적용되는 OpenAI 서비스 약관과 프로젝트 배포 정책을
따른다. 각 에셋의 생성 브리프(`prompt`), 생성 식별자, 책임 주체, 라이선스 분류,
checksum은 `asset-manifest.json`에 기록한다. 이는 제3자 사진·브랜드·앱 화면을
참조하거나 재사용했다는 뜻이 아니다.

## Fonts

- Pretendard: SIL Open Font License 1.1  
  원본 안내: https://github.com/orioncactus/pretendard/blob/main/LICENSE
- MaruBuri: NAVER 나눔글꼴과 같은 SIL Open Font License 1.1 적용  
  원본 안내: https://help.naver.com/service/30016/contents/18088?osType=PC

두 글꼴의 copyright notice와 OFL 1.1 전문은 배포 APK에도
`assets/licenses/FONT-LICENSES.txt`로 포함된다. 이 저장소의 출시 전 확인용 사본은
`android-app/app/src/main/assets/licenses/FONT-LICENSES.txt`이다.
