# implement_20260730_102025.md

작성 일시: `2026-07-30 10:20:25 KST`

이 문서는 Android 로컬 AI 모델을 앱 교체 때마다 다시 받는 문제를 막고, 사용자가
명시적으로 삭제하기 전까지 다운로드·가져오기 원본과 설치 모델을 보존하기 위한 개발
범위를 고정한다.

## 개발 목적

- Samsung 사용자 확인 앱을 `com.thinktank.recorder.next.qa`로 고정하고 동일 서명
  `adb install -r` 업데이트만 허용한다.
- 다운로드·가져오기 원본을 앱 내부 보관소에 유지해 APK 덮어쓰기나 설치 중단 뒤에도
  네트워크 없이 모델을 복구한다.
- 사용자가 지정한 공유 모델 보관함에 원본을 복제해 앱 삭제 후에도 파일 자체는 남긴다.
- 앱 내부 모델이 없으면 검증된 내부 원본 또는 공유 보관함 원본으로 자동 복구하되,
  사용자 동작 없이 네트워크 다운로드를 시작하지 않는다.
- 모델 삭제를 명시적인 확인 작업으로 바꾸고 적용본과 보관 원본 삭제 범위를 구분한다.

## 개발 범위

1. Samsung `.qa` 고정 빌드·설치 스크립트와 파괴적 명령 정적 방어
2. 모델 원본의 내부 artifact 보관 및 SHA-256 기반 로컬 복구
3. Storage Access Framework 기반 공유 모델 보관함 연결·보존·복구
4. 모델 적용본만 삭제 / 보관 원본까지 완전 삭제 UI와 저장소 정책
5. 단위·빌드·스크립트·Samsung 실기기 비파괴 회귀

## 제외 범위

- 모델 추론 알고리즘, STT/LLM 품질 정책, 모델 카탈로그 자체 교체
- 사용자 동작 없는 Qwen, EXAONE, Gemma, SenseVoice 네트워크 다운로드
- 외부 클라우드, 서버 STT/LLM, 녹음·전사문 외부 전송
- 기존 사용자 녹음·노트·아카이브의 삭제 또는 일괄 변환
- `com.thinktank.recorder.next.qa` 대상 `adb uninstall`, `pm clear`, connected instrumentation
- Samsung `SM-S931N` (`R3CY40PXCAP`) 이외 실기기 사용

## 문서 기반 제약 사항

- Android `filesDir`는 같은 application ID와 서명의 APK 덮어쓰기에는 유지되지만 앱 삭제,
  데이터 초기화, 다른 application ID 설치에는 공유되지 않는다.
- 공유 모델 보관함 파일은 앱 삭제 후에도 남지만 Android 권한은 사라질 수 있으므로 재설치
  후 사용자가 같은 폴더를 다시 연결해야 한다.
- 모델 실행 라이브러리는 일반 파일 경로를 요구하므로 공유 보관함 원본은 검증 후 앱 내부
  실행 공간으로 복원한다.
- 모델 원본 보관으로 저장공간 사용량이 늘어날 수 있으므로 UI에 적용본/보관본 범위를
  구분해 표시하고 삭제 선택권을 제공한다.

## 잔여 리스크

- 앱을 Android 설정이나 `adb`로 삭제/데이터 초기화하면 내부 적용본과 내부 artifact는
  Android 정책상 삭제된다. 이 경우 공유 보관함을 다시 연결하면 로컬 복구할 수 있다.
- Qwen, EXAONE, SenseVoice는 이번 작업에서 현재 카탈로그와 일치하는 로컬 원본이 없어
  자동 다운로드하지 않았다. 사용자가 각 설치 버튼을 명시적으로 누른 경우에만 받는다.
- 내부 artifact와 적용본을 함께 유지하므로 모델 하나당 앱 내부 저장공간은 대략 두 배
  사용한다. 공유 보관함까지 연결하면 공유 원본 용량이 추가된다.
