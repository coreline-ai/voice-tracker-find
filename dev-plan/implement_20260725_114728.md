# implement_20260725_114728.md

작성 일시: `2026-07-25 11:47:28 KST`

이 문서는 로컬 AI 4번째 탭에서 확인된 10개 기술 결함을 수정하는 추가 개발 범위를
고정하고, 기존 녹음·동기화·노트 기능의 회귀 없이 구현하기 위한 작업 문서다.

라이선스, 고지, 상업 정책 등 비기술 항목은 이 계획에서 다루지 않는다.

## 개발 목적

- 녹음·전사·요약 작업을 하나의 취소 가능한 상태 머신으로 통합한다.
- 실패·취소·프로세스 종료 후 DB 상태와 보존 파일이 항상 일치하게 만든다.
- Moonshine 실패 세션을 저장된 WAV에서 다시 전사할 수 있게 한다.
- 녹음·추론 중 삭제와 lifecycle 시작 경쟁을 제거한다.
- `AudioRecord`와 Android SpeechRecognizer의 모든 terminal 경로를 보장한다.
- 기존 `RecorderService`의 종료·복구·신규 시작 순서를 직렬화한다.
- Qwen을 별도 프로세스로 분리해 성공·실패·취소 후 native 메모리를 확실히 회수한다.
- 모델 다운로드·설치·삭제를 모델 ID 단위로 직렬화한다.
- 비-arm64 기기에서는 기존 앱 기능을 유지하고 지원되지 않는 native AI 기능만 차단한다.
- 구현 전후 동일한 회귀 명령을 실행해 테스트 실패 증가를 0건으로 유지한다.

  coroutine과 기존 native runtime으로 구현한다.

## 상태·데이터 계약

### 추가 상태

- `STARTING`: 사용자 요청을 받았으나 engine 시작 전
- `AUDIO_READY`: Moonshine용 WAV가 정상 마감됐고 전사 가능
- `CANCELLING`: 취소 cleanup과 DB terminal 전이 진행 중
- `DELETING`: operation 시작을 차단하고 파일·DB 삭제 진행 중

### operation 종류

- `LIVE_STT`
- `LOCAL_CAPTURE`
- `MOONSHINE_TRANSCRIBE`
- `KOTLIN_SUMMARY`
- `QWEN_SUMMARY`

### 취소 결과

| 취소 시점 | 보존 데이터 | DB 결과 |
|---|---|---|
| system STT 시작/듣기 | 확정 transcript 없음 | `CANCELLED` |
| Moonshine 녹음 중 | partial WAV 삭제 | `CANCELLED` |
| Moonshine 전사 중 | 정상 WAV 보존 | `AUDIO_READY` |
| Kotlin/Qwen 요약 중 | transcript 보존 | `TRANSCRIPT_READY` |
| 삭제 중 실패 | 남은 파일/행과 오류 보존 | `FAILED_RECOVERABLE`, stage `DELETE` |

### process-death 복구

| 중단 상태 | 검증 | 복구 상태 |
|---|---|---|
| `STARTING`, live `LISTENING` | 확정 입력 없음 | `CANCELLED` |
| local `LISTENING` | WAV header·길이 검증 | 유효하면 `AUDIO_READY`, 아니면 `FAILED_RECOVERABLE` |
| `TRANSCRIBING` | WAV 존재·형식 검증 | `AUDIO_READY` |
| `SUMMARIZING` | transcript 존재 확인 | `TRANSCRIPT_READY` |
| `CANCELLING` | failure stage와 보존 파일 확인 | 위 단계별 terminal 상태 |
| `DELETING` | 파일·DB 잔존 확인 | 삭제 재시도 가능한 `FAILED_RECOVERABLE` |
