작성 일시: `2026-07-27 07:58:54 KST`

## 목적

현재 Samsung 전용 Compose 앱의 4번째 탭(로컬 AI)을 **외부 추론 없이** 신뢰할 수 있는
beta 상태로 만든다. 기존 Qwen/SenseVoice 경로의 품질·취소·데이터 보존·실기기 증적을
먼저 닫고, 그 결과가 부족할 때만 새 모델을 **한 개씩** 검증한다.

## 범위와 고정 제약

### 포함

1. 기존 SenseVoice 파일 전사와 Qwen 요약의 오류 원인·품질·수명주기 안정화
2. `com.thinktank.recorder.next.qa` 데이터를 보존하는 Samsung 실기기 회귀
3. 기존 녹음/동기화/노트·아카이브/대시보드의 최소 회귀 확인
4. 안정화 결과에 따른 단일 차기 모델 후보의 결정 문서

### 제외

- GCP, 외부 STT/LLM API, 클라우드 추론, 녹음·전사문 업로드
- 현재 untracked `cloud_*`, PostgreSQL, Docker, migration 초안의 구현·커밋·삭제
- 기존 녹음·모델·로컬 AI 기록의 삭제, 일괄 재작성, `adb uninstall`, `pm clear`
- PD20 또는 Samsung `SM-S931N` (`R3CY40PXCAP`) 이외 실기기 사용
- EXAONE와 Gemma의 동시 도입, 검증 전 기본 모델 승격

### 공통 규칙

- 추론 중 네트워크 연결은 0건이어야 한다. 모델 다운로드만 사용자가 명시적으로 시작한
  validated Wi-Fi에서 허용한다.
- 원본 오디오, 전사문, 모델 raw 출력, 비밀값은 logcat·PC 파일·계획 문서에 기록하지 않는다.
- 사용자 확인용 `.qa`에는 동일 서명 APK를 `adb install -r`로만 적용하고, 자동 테스트는
  `.deviceTest`에서만 수행한다.
- 기존 Mac mini LAN receiver는 유지한다. 이 계획은 서버를 외부 클라우드로 이전하지 않는다.

- [ ] Samsung `R3CY40PXCAP`에서 로컬 AI와 기존 녹음 흐름이 비파괴로 검증된다.
- [ ] 외부 추론과 녹음·전사 업로드 없이 모든 로컬 AI 처리와 fallback이 설명 가능하다.
- [ ] 모델 확장 여부는 측정 결과와 단일 후보 승인 기록에 따라 결정된다.
