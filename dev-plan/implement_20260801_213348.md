## 개발 목적

- 합성 TTS 5건에서 발견된 Gemma 요약 허위 양성을 자동 회귀로 고정한다.
- 원문 단어 일부만 겹치는 비문·주제 누락 결과가 정상 요약으로 저장되지 않게 한다.
- 새 품질 계약을 validation status와 generation profile에 명시해 기존 결과와 구분한다.
- Python 테스트가 직접 import하는 개발 의존성을 선언하고 재현 가능한 테스트 환경을 만든다.
- 현재 작업 트리의 Android 단위 테스트·lint·APK assemble과 Python 테스트를 다시 검증한다.
- 연결된 승인 Samsung에서 비파괴 instrumentation과 Gemma V5/V6 합성 TTS 품질을 검증한다.

## 개발 범위

1. Gemma 단문 요약의 완결성·주제 보존 gate 보강
