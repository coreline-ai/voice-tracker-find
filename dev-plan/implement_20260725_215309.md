# implement_20260725_215309.md

작성 일시: `2026-07-25 21:53:09 KST`

이 문서는 Moonshine 한국어 STT를 제품 경로에서 제거하고, Android/Samsung의 시스템
온디바이스 STT만 지원하도록 범위를 고정하는 작업 문서다.

## 개발 목적

- 로컬 AI 탭의 음성 인식을 Android `createOnDeviceSpeechRecognizer` 기반의 시스템
  온디바이스 STT 단일 경로로 고정한다.
- Moonshine 선택·다운로드·모델 설치·전사·재전사·라이선스 화면·native 런타임을 제거한다.
- 기존 Moonshine 선택 설정과 과거 세션이 앱 업그레이드 뒤에도 충돌 없이 보존·삭제 가능하게 한다.

## 개발 범위

- `SttEngineType`을 시스템 온디바이스 STT 단일 값으로 축소하고, 기존 저장 설정은 자동으로
  시스템 STT로 되돌린다.
- 화면에서 STT 선택 카드와 Moonshine 라이선스/모델 카드를 제거하고, 시스템 STT의 사용 가능
  여부와 불가 안내만 표시한다.
- Moonshine 전사·WAV 전사 재시도·sherpa-onnx JNI/바인딩·압축 설치 경로·Moonshine QA를 제거한다.
- 모델 관리는 Qwen 로컬 요약 모델만 유지한다. Qwen 요약, Kotlin 추출 요약, 기존 로컬 기록은
  범위에 포함되지 않는 기존 기능으로 보존한다.
- 기존 Moonshine 세션은 표시와 삭제만 유지한다. 재전사 버튼을 노출하지 않으며, 설치 모델 파일은
  자동 삭제하지 않는다.

## 제외 범위

- 시스템 STT가 없는 단말을 위한 새 다운로드형 STT 추가
- 시스템 언어팩의 자동 설치·기기 설정 변경·네트워크 STT 전환
- Qwen 모델/요약 기능, 서버 동기화, 일반 녹음 기능 변경
- 기존 기기에 저장된 Moonshine 모델 파일의 자동 삭제 또는 사용자 세션 삭제
