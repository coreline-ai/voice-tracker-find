# implement_20260726_201251.md

작성 일시: `2026-07-26 20:12:51 KST`

이 문서는 4번째 탭 로컬 기록 카드에서 전사 원문이 잘려 보이는 문제와, Qwen 요약이
원문을 다시 늘어놓아 요약의 의미를 잃을 수 있는 문제를 수정하기 위한 작업 문서다.

## 개발 목적

- 카드 미리보기와 별도로 스크롤 가능한 전체 전사 보기를 제공해, 저장된 원문 전체를 사용자가 확인하게 한다.
- Qwen 로컬 요약은 원문 고유 내용을 반영하되, 항목 수를 억지로 채우지 않고 핵심만 짧게 남긴다.
- 저장·표시되는 핵심 요약 본문은 항상 원문보다 짧고, 정규화한 원문 글자 수의 15% 및 80자 이내로 제한한다.
- 기존 Samsung의 1분 7초 완료 녹음을 원본 변경 없이 다시 선택해 `PCM → SenseVoice → Qwen`을 실제 UI에서 검증한다.

## 개발 범위

1. 로컬 기록 카드의 전사 원문은 미리보기 6줄을 유지하되, 글자 수와 `전체 전사 보기`를 추가한다.
2. 전용 바텀시트에서 전체 전사 원문을 선택 가능·세로 스크롤 가능하게 표시한다.
3. Qwen JSON 계약과 Kotlin fallback의 최종 출력 모두를 `1~2개 · 항목당 30자 · 전체 15%/80자`로 제한한다.
4. 원문 문장을 보강해 항목 수를 채우는 처리(원문 근거 보강)는 신규 결과에서 제거한다.
5. parser/UI 테스트와 실기기 수동 UI 테스트를 수행한다.

## 제외 범위

- SenseVoice 모델·VAD·PCM 변환·일반 녹음 동작 변경
- Qwen 모델 교체, 모델 다운로드, 네트워크·클라우드 사용
- 기존 원본 녹음·전사·기존 로컬 기록의 삭제 또는 수정

### 구현 태스크

## 2026-07-26 수정 방향 확정

- `4개 이상`을 채우기 위해 원문 조각을 덧붙인 방식은 **요약이 아니라 확장**이므로 폐기한다.
- 신규 핵심 요약은 원문의 핵심만 남긴 `1~2개` 행이며, 저장되는 행 합계(줄바꿈 포함)는 정규화 원문의 `15%` 및 `80자`를 넘지 않는다.
- Qwen이 이 조건을 만족하지 못하면 결과를 Qwen으로 가장하지 않고 Kotlin 추출형 결과를 같은 상한으로 압축해 저장한다.
- 기존 기록·원본 M4A는 수정하거나 삭제하지 않는다. 새 앱에서 동일 원본을 다시 분석한 새 기록만 이 계약으로 검증한다.

## 2026-07-26 2차 압축 보정

- 첫 압축 상한(`1~3개 · 45자 · 30%/160자`)도 카드에서 여러 줄로 보일 수 있어, 사용자가 원하는 “핵심만 짧게” 기준에 맞지 않는 것으로 재판정했다.
- 최종 계약은 `1~2개 · 행당 30자 · 전체 15%/80자`다. 카드의 제목·섹션 제목을 다시 말하는 `비교 결과:` 등의 bullet 접두어는 제거한다.
- 실제 1분 7초 전사에 대해 Qwen 직접 실행이 이 계약을 통과함을 먼저 확인했다.
- UI 재분석 중 빠른 요약으로 저장된 경우는 Qwen 모델 문제가 아니라 현재 선택 설정이 빠른 요약이었던 경우였다. Qwen을 명시 선택한 후 동일 원본을 재분석했고 최종 읽기 전용 assertion을 통과했다.
