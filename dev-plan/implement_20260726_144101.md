# implement_20260726_144101.md

작성 일시: `2026-07-26 14:41:01 KST`

이 문서는 Samsung 시스템 STT가 녹음 파일 PCM 입력을 거부한 결과를 반영하여, 4번째 탭의
**완료 녹음 파일 전사만** SenseVoice 기반 로컬 STT로 대체하는 개발 범위를 고정한다. 실시간
마이크 STT는 기존 Android 시스템 온디바이스 STT를 유지한다.

## 개발 목적

- 1번 탭의 완료 M4A/WAV 녹음을 네트워크 없이 한국어 텍스트로 전사한다.
- STT 모델 다운로드는 validated Wi-Fi에서만 허용하고, 설치·전사·요약은 기기 내부에서만 처리한다.
- 기존 PCM 정규화, 안전 snapshot, 전사 스크롤 UI, Qwen/Kotlin 요약 선택 흐름을 재사용한다.

## 개발 범위

1. SenseVoice INT8 archive를 SHA-256 고정값으로 Wi-Fi 전용 다운로드·검증·안전 설치한다.
2. `model.int8.onnx`와 `tokens.txt`를 설치 모델로 관리하고, arm64 native runtime을 앱 배포물에 포함한다.
3. 완료 녹음 snapshot → 16 kHz mono PCM → VAD 분할 → SenseVoice 파일 전사 → 전사문 병합을 구현한다.
4. 4번째 탭에서 STT 모델 설치 상태·진행·실제 사용 엔진을 명확히 표시한다.
5. Samsung SM-S931N에서 모델 설치, 실제 M4A 전사, Kotlin/Qwen 요약, Wi-Fi 단절·취소·정리 회귀를 검증한다.

## 제외 범위

- Moonshine 재도입, Android 시스템 STT로 녹음 파일을 재시도하는 우회 경로
- 클라우드 STT·LLM·음성/전사문 업로드, 모바일 데이터·테더링 다운로드
- 녹음 파일을 스피커로 재생해 마이크로 다시 전사하는 방식
- 다중 언어 모델 선택, 다수 녹음 병합, 화자 분리
- 모델 설치 완료 전 파일 전사 버튼 활성화

## 공통 진행 규칙

- 각 Phase는 앞선 Phase의 자체 테스트 완료 후에만 시작한다.
- 모델 원격 전송은 `WIFI + INTERNET + VALIDATED` 연결에 socket과 DNS를 바인딩한 경우만 허용한다.
- Wi-Fi 이탈 시 모바일 데이터로 전환하지 않는다. partial artifact는 유지하고 Wi-Fi 복귀 뒤에만 재개한다.
- 모든 원격 artifact는 HTTPS, 허용 host, 고정 size, SHA-256을 통과해야 설치한다.
- 전사·요약 중에는 네트워크를 열지 않으며, 원본·PCM·전사문을 로그나 외부 저장소로 반출하지 않는다.
- Samsung 고정 대상은 `R3CY40PXCAP`뿐이다. PD20은 개발·설치·테스트 대상에서 제외한다.
- 문서에 없는 STT 엔진, 업로드 경로, 원본 자동 삭제 기능은 추가하지 않는다.
