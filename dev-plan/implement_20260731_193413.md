## 개발 목적

- 현재 앱의 실제 지원 범위를 SenseVoice 파일 STT와 Gemma 3 1B 단일 요약으로 정리한다.
- 계층형 요약이 결과 카드에 정상 표시되고, 한 문장만 표시되는 문제를 개선한다.
- 구조적 트리 연결뿐 아니라 각 요약 노드가 실제 하위 입력에 근거했는지 검증한다.
- 제거된 Qwen·EXAONE의 내부 파일을 사용자가 확인 후 안전하게 정리할 수 있게 한다.
- 2시간 경계·중단 복구를 자동 검증하고 Samsung 장시간 실측 항목을 별도 gate로 유지한다.
- Cloud API는 배포 가능한 범위와 미구현 worker/IaC 범위를 명확히 분리한다.
